# Fertilizer Recommendation Dataset — Methodology & Provenance

## Overview
This dataset provides labelled fertilizer recommendations (type + amount) for 17
staple field crops of India, derived from soil and agro-climatic inputs using a
transparent, citation-anchored nutrient-balance method grounded in the Indian
Soil Test Crop Response (STCR) / General Recommended Dose (GRD) framework.

- Records: 1,700 (17 crops x 100 field-condition instances)
- Inputs (features): crop, soil N, soil P, soil K, temperature, humidity, pH, rainfall
- Outputs (labels): fert_N_kg_ha, fert_P2O5_kg_ha, fert_K2O_kg_ha,
  total_fertilizer_kg_ha, fertilizer_type

## Derivation method (nutrient balance, STCR/GRD-anchored)

Step 1 — Crop reference dose.
For each crop, the General Recommended Dose (GRD) of N:P2O5:K2O (kg/ha) was taken
from authoritative ICAR / AICRP / State Agricultural University sources
(see fertilizer_dataset_sources_citations.csv). The GRD is, by definition, the
fertilizer dose calibrated for a soil of MEDIUM fertility.

Step 2 — Soil-responsive adjustment (the balance step).
Each field's soil-available N, P, K is compared to a medium-fertility reference
computed PER CROP (the median soil N, P, K among that crop's records). A per-crop
reference is essential: different crops occupy different typical soil-fertility
ranges, so a single global reference would systematically bias doses (penalising
crops grown on naturally richer soils and inflating doses for crops on poorer
soils). Fields richer than typical for that crop receive a proportionally reduced
dose; poorer fields receive an increased dose:

    relative_status  = (soil_value - crop_reference) / crop_reference   (clipped to [-1, +1])
    adjustment_factor = 1 - 0.5 * relative_status                       (range 0.5 .. 1.5)
    fertilizer_nutrient = GRD_nutrient * adjustment_factor

This mirrors the core STCR principle: fertilizer need = crop requirement adjusted
for indigenous soil supply. The ±50% bound keeps values within the agronomically
realistic envelope reported in Indian STCR field trials. By construction, the mean
recommendation for each crop reproduces its verified GRD (validated to within
~1.5% for all 17 crops), while individual fields vary according to soil status.

Step 3 — Fertilizer TYPE assignment (real product chemistry).
The dominant nutrient in the computed requirement determines the recommended
product, using fixed fertilizer compositions (Urea 46% N; DAP 18% N + 46% P2O5;
MOP 60% K2O):
  - Nitrogen-dominant  -> Urea
  - Phosphorus-dominant -> DAP
  - Potassium-dominant  -> MOP
  - Balanced N-P-K      -> NPK complex
  - Mixed               -> DAP + Urea / Urea + MOP

## Nutrient-use-efficiency note
Standard Indian recovery-efficiency values (N ~45%, P ~18%, K ~65%) informed the
interpretation but were NOT used to divide raw nutrient gaps (which would inflate
P unrealistically). The GRD already embeds fertilizer-use efficiency, so the
soil-responsive adjustment is applied to the GRD directly. This is the
scientifically correct treatment.

## Honest scope and limitations (state these in the paper)
1. This is a METHOD-DERIVED (synthetic) dataset, not field-measured fertilizer-
   response data. It is a transparent proof-of-concept for ML-based fertilizer
   recommendation, NOT a field-validated prescription system.
2. Because labels are generated by a deterministic nutrient-balance rule, an ML
   model trained on this data primarily learns to approximate that rule; it does
   not discover new agronomic relationships. Field validation with measured
   fertilizer-yield trial data is the necessary next step before deployment.
3. GRD values are national/representative; true STCR coefficients are region- and
   soil-specific. Two crops (bajra upgraded to HIGH; coriander MEDIUM) had less
   precise source values and are flagged in the citation table.
4. The medium-fertility reference is computed per crop from dataset medians; a
   soil-testing-laboratory calibration (using official soil-test rating classes:
   low/medium/high) would refine this in a field deployment.
5. Validation check: for all 17 crops, the mean generated recommendation matches
   the sourced ICAR/AICRP GRD to within ~1.5%, confirming the derivation is
   correctly anchored to the authoritative doses.

## Suggested methods-section sentence
"Fertilizer requirements were derived using a nutrient-balance approach anchored
to ICAR/State Agricultural University General Recommended Doses, made soil-
responsive by adjusting each crop's recommended dose according to field soil-test
values relative to a medium-fertility reference. This follows the principle
underlying the Soil Test Crop Response (STCR) methodology. As a method-derived
dataset, it serves as a proof-of-concept requiring field validation before
deployment."
